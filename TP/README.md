# Descriptive Statistics with Python

Exploratory Data Analysis (EDA) of medical insurance and house pricing datasets using Python.

## Technologies

- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Jupyter Notebook

## Project Overview

This project explores two datasets through descriptive statistics and data visualization.

### 1. Medical Insurance Analysis

- Data exploration and filtering
- Mean and standard deviation
- Skewness and kurtosis
- Relationship between age, smoking status and medical charges

### 2. House Pricing Analysis

- Missing value handling
- Statistical analysis of house prices
- Histograms and density plots
- Correlation matrix and heatmap
- Scatter plots and boxplots

## Key Findings

House prices are strongly associated with overall quality and living area. Medical insurance charges tend to be higher among smokers.

## How to Run

Install the required Python libraries:

```bash
pip install pandas numpy matplotlib seaborn scipy jupyter
```

Open `Descriptive_statistics.ipynb` in Jupyter Notebook or VS Code and run the cells.
